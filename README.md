# Vendora

Multi-vendor POS and ecommerce backend. Development runs inside a VS Code Dev Container.

The backend foundation is implemented and verified against development PostgreSQL. You can register, log in, create a vendor with an initial branch, and list, view, or rename vendors through membership-protected API endpoints. There is no storefront or POS interface yet. Database persistence across a Compose restart still needs verification.

Start with the [hands-on testing guide](docs/testing.md). See [development instructions](docs/development.md) and the [product plan](docs/plan.md).
